# Unstable StateV2 Module

This module has been converted from Kotlin to Java. The Java implementation is a work in progress.

## Previous Functionality

This module previously provided:
- State v2 implementations
- Tracked collections (MutableTrackedList, MutableTrackedSet, etc.)
- State combinators
- Coroutine support for states

## Current Status

The module is empty pending full Java implementation. The core Elementa library has been fully converted to Java.
